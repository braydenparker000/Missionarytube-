# Release checklist
Use only relevant items; retain required repository controls.
- Requested outcome and exclusions still match the patch.
- Exact reviewed revision; diff contains no unrelated changes or secrets.
- Appropriate tests passed; baseline findings distinguished from regressions.
- Known TODOs/limitations accurately classified; no false readiness claim.
- Required approval and current permissions verified.
- Build artifact, source/dependency/config identity and destination recorded.
- Rollback/recovery available; data changes compatible with rollback plan.
- Existing deployment mechanism used; no unnecessary new publisher.
- Write acceptance reconciled; no uncertain duplicate publish.
- Merge, deployment and live verification recorded separately.
- Real target smoke/observations completed where applicable.
- User informed once in the appropriate channel with material limitations.
