# Evidence — Astra mobile design foundation

Captured with headless Chromium (Playwright, mobile emulation, `deviceScaleFactor: 2`)
against a **local** throwaway harness: a `127.0.0.1` HTTP server that serves this
repository plus two synthetic Stremio add-ons. Every catalog, title, poster,
episode and stream name in these screenshots is generated by that harness. No
real add-on, no configured manifest URL, no debrid account and no personal data
was used, and the harness is not part of the deployable app.

The two synthetic providers are deliberately overlapping: both publish a catalog
called **Popular**, so the screenshots show how a rail, a browse grid and a
result keep their add-on identity when names collide.
